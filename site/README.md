# Lumen — site público (GitHub Pages)

Página estática da **Política de Privacidade** para a ficha da Play Store / App Store.

## URL

https://goobinexe.github.io/lumen-privacy/

O repositório do app (`TDAH`) é privado. Esta pasta `site/` é a fonte; o conteúdo público vive no repositório **`lumen-privacy`** (só a página).

## Atualizar

1. Edite `docs/PRIVACY.md` e esta `site/index.html` no mesmo sentido.
2. Copie / faça push de `site/` para o repo público `lumen-privacy` (branch `main`, Pages em `/` root).
