# Internacionalização (i18n) — Lumen / noa

## Visão geral

- **Template (fonte da verdade):** [`lib/l10n/app_pt.arb`](../lib/l10n/app_pt.arb) (português)
- **Locales:** `pt`, `en`, `es`, `ja`
- **Geração:** Flutter `gen-l10n` → `AppLocalizations`
- **Config:** [`l10n.yaml`](../l10n.yaml) + `flutter: generate: true` no `pubspec.yaml`
- **Acesso:** `AppLocalizations.of(context)` ou `ref.watch(appLocalizationsProvider)` / `lookupAppLocalizations(locale)` (PDF, WhatsApp, engine)

## Fluxo de trabalho

1. **Adicionar / editar strings** só em `lib/l10n/app_pt.arb`
   - Chaves em `camelCase`
   - Placeholders ICU com metadados `@chave`
   - Em textos clínicos / longos, inclua `"description"` no `@chave` (contexto para o doloc)

2. **Traduzir alvos** com [doloc](https://doloc.io/getting-started/frameworks/flutter/):
   ```bash
   export API_TOKEN=seu_token
   dart run tool/doloc.dart
   flutter gen-l10n
   ```
   O script envia `app_pt.arb` como fonte e atualiza `app_en.arb` / `app_ja.arb` / `app_es.arb`.

3. **Usar na UI:**
   ```dart
   final l10n = ref.watch(appLocalizationsProvider);
   Text(l10n.welcomeUser('Marcelo'));
   ```

## Quando rodar o doloc

- Depois de **novas chaves** no `app_pt.arb`
- Depois de **alterar o texto** de uma chave: remova a entrada correspondente nos alvos para forçar retradução
- Antes de commit, revise as traduções geradas

## Notas

- Não edite `app_localizations*.dart` — são gerados.
- Labels/associações do State of Mind ficam nos mapas em `state_of_mind_*.dart` (já multilíngues); passe o `languageCode` do locale ativo.
- Token: variável `API_TOKEN` (não commitar em repositório público).
- Nome do usuário / paciente ainda está fixo (“Marcelo”); placeholder `{name}` já existe para perfil futuro.
